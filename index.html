Self-Hosted Web App

Eve Workspace

Your AI workspace. Self-hosted, self-aware of its limitations.

A multi-provider LLM web interface you run on your own machine. Chat with Claude, Gemini, or local models through a single UI. Warm-started persistent processes mean no cold boot penalties between messages. Real-time token and cost tracking so you can watch your money disappear in real time. Includes a file browser, Monaco editor, scheduled tasks, and a terminal—because apparently one IDE wasn't enough.

  • Multi-provider: Claude, Gemini, LM Studio (local models)
  • Persistent CLI processes with warm starts
  • Real-time token and cost tracking
  • Integrated tools: file browser, editor, tasks, terminal
  • WebAuthn passkey authentication

Safari Extension

Pace Reader

Speed reading, the RSVP way

A Safari extension for RSVP speed reading plus a native iOS app. Read faster by eliminating eye movement. Save articles to speed read later—share from Safari, extract via Action Sheet, or paste URLs directly in the app. Customize display and speed settings that sync across all devices.

  • 100-1000 WPM speed control with presets
  • Optimal Recognition Point highlighting
  • iOS Share Sheet and Action Sheet integration
  • Customizable display and behavior settings
  • Alledgedly works with some web-based eBook stores in the Pacific Northwest (use the Safari extension feature)

macOS App

Sorta Sleep

Why won't your Mac sleep? Maybe find out.

A native macOS diagnostic tool for investigating why your Mac refuses to sleep like a reasonable computer. Runs diagnostic checks across sleep prevention, wake issues, power configuration, and hardware. Uses Apple Intelligence to analyze raw pmset output and explain it in human words, because life's too short to read kernel logs. Since it uses Apple AI, it can only get better over time. Right? RIGHT, APPLE?! Applies fixes with full undo support, in case you break something.

  • Apple Intelligence summarizes diagnostics in plain English
  • 24-hour drag-to-zoom timeline of sleep, wake, and dark wake events
  • Monitors sleep assertions, caffeinate processes, battery, Bluetooth, USB
  • One-click fixes for Power Nap, WoL, Proximity Wake, TCP Keep Alive
  • Full action log with undo, exportable, persisted across sessions
